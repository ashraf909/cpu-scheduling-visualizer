# CPU Scheduling Algorithm Visualizer

A website that draws Gantt charts and calculates completion, turnaround and waiting time for four CPU scheduling algorithms, and compares them.

Built with plain HTML, CSS and JavaScript (no framework, no backend). Operating Systems lab project.

## Features

- **Module 1 - Algorithm visualization:** choose FCFS, SJF, Priority (either priority order) or Round Robin, enter arrival / burst / priority values, see the Gantt chart, the process table, average waiting time, average turnaround time, total CPU idle time and CPU utilization. A Play / Step mode replays the schedule one time unit at a time.
- **Module 2 - Comparative analysis:** pick two or more algorithms, see a Gantt chart for each, a comparison table, a written verdict and two charts.
- Input validation, example data, random data, saved inputs, dark mode, print / save as PDF, mobile layout.

## How to run

Open `index.html` in a browser. No install needed. (The chart library loads from the internet, so you need a connection for the Module 2 charts.)
